**Status tier definitions (include these in the document):**
- **Covered**: Specific detectable patterns with test cases validated
- **Partially Covered**: Some sub-categories covered, others not
- **Not Covered**: Category is in scope but not yet implemented
- **Not Detectable**: Category requires context unavailable in single-file code analysis (structural limitation)

List the specific safe patterns the skill is trained NOT to flag:

- This skill analyzes single files. Cross-file taint analysis is not performed.
- If the skill cannot determine whether input is user-controlled, it reports "cannot determine" rather than flagging.
- File analysis is capped at 300 lines.
- Only Java and JavaScript/TypeScript are supported in this version.
